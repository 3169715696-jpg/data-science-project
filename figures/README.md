# Figures

Both images are generated by `../anage_analysis.py` (300 dpi PNG, matplotlib). Re-running the
script overwrites them byte-for-byte — no sampling, no random state.

| File | What it shows |
|---|---|
| `main_mass_vs_longevity.png` | Hero chart: log–log scatter of body mass against maximum longevity for 530 species, one fitted OLS line per class (mammals, birds), reptiles as points only, the 1 kg comparison band and the labelled exceptions. |
| `class_scaling_summary.png` | Companion chart: the same fits evaluated at five fixed body masses (10 g → 100 kg), making the constant bird-over-mammal offset (×1.76 → ×2.20) explicit. |

Numbers behind both charts: `../results/fits.json`.
